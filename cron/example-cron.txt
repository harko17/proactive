# Proactive

This project automates a New Relic dashboard export to an Excel file and is designed to run on a cron schedule.

## What it does

- Opens the New Relic login page
- Logs in using environment variables
- Opens the target dashboard
- Extracts predefined monitoring values from the rendered text
- Writes the extracted values into `output/proactive_report.xlsx`

## Setup

1. Create a virtual environment
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

2. Install Python dependencies
   ```bash
   pip install -r requirements.txt
   playwright install chromium
   ```

3. Copy env file and fill real values
   ```bash
   cp .env.example .env
   ```

4. Update your New Relic credentials and dashboard URL in `.env`.

## Run once

```bash
python app/newrelic_client.py
```

## Cron example

```cron
0 * * * * cd /path/to/proactive && source .venv/bin/activate && python app/newrelic_client.py >> logs/proactive.log 2>&1
```

## Notes

- This project expects your dashboard to be accessible after login.
- For production use, keep credentials in `.env` or a secret manager and never commit them.
- If the New Relic DOM changes, update the metric names/regex list in `app/config.py`.
